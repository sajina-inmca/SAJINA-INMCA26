# Contributing to the Student Project

Thank you for contributing to this Python student project! This guide explains how to report problems, suggest improvements, and contribute code.

## 1. How to Report an Issue

If you find a problem:

1. Open the project's **Issues** section.
2. Create a new issue.
3. Clearly describe the problem.
4. Explain how to reproduce the problem.
5. Add any useful information.

## 2. How to Suggest a Feature

If you have an idea for a new feature:

1. Open the project's **Issues** section.
2. Create a new issue.
3. Explain the feature you suggest.
4. Describe how it could improve the project.

## 3. How to Create a Branch

Create a separate branch before making changes.

Use a clear branch name, for example:

```text
feature/add-calculator
```

Keep the branch name related to your changes.

## 4. How to Make Changes

1. Create a branch.
2. Make the required changes.
3. Keep the code simple and readable.
4. Save your changes.
5. Check that your changes work correctly.

## 5. How to Test Changes

Before submitting your changes:

1. Run the Python program.
2. Check that it works as expected.
3. Test the new feature or change.
4. Make sure your changes do not cause existing features to stop working.

## 6. How to Create a Pull Request

After completing and testing your changes:

1. Push your branch to the project repository.
2. Open a **Pull Request**.
3. Give the pull request a clear title.
4. Explain what you changed.
5. Explain how you tested the changes.
6. Submit the pull request for review.

## 7. Basic Coding Guidelines

Follow these simple guidelines:

- Write clear and readable Python code.
- Use meaningful names for variables and functions.
- Keep functions simple.
- Add comments when they are helpful.
- Avoid unnecessary code.
- Keep formatting consistent.
- Test your code before submitting changes.

## Thank You

Thank you for helping improve this student project!
